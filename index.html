Zihao He 何子浩

I am a Ph.D. student at University of Maryland, advised by Prof. Hao-Shu Fang and I also collaborate closely with Prof. Ruoshi Liu. I received my B.Eng. degree from Shanghai Jiao Tong University, where I was a member of the Machine Vision and Intelligence Group (MVIG) under the supervision of Prof. Hao-Shu Fang and Prof. Cewu Lu. I was also a visiting research intern at UC San Diego, working with Prof. Hao Su.

My research interests mainly lie in dexterous manipulation, tactile sensing, and cross-embodiment learning with the ultimate goal of building intelligent robots with human-level manipulation dexterity.

    Rethinking Visual Embodiment Dependence in Visuomotor Policies
    Hongjie Fang, Yuxuan Lu, Chenxi Wang, Haoxiang Qin, Shirun Tang, Zihao He, Shangning Xia, Jingjing Chen, Wanxi Liu, Shiquan Wang†, Cewu Lu†
    arXiv, 2026
    paper / project page

    Visuomotor policies can use a robot's visible configuration as a shortcut. A shared 3D representation supports human-to-robot transfer, and data augmentation improves robustness to unseen robot configurations.

    MATE: Asynchronous Multi-Rate Diffusion Policy Composition
    Zihao He*, Hongjie Fang*, Shirun Tang, Cewu Lu†, Hao-Shu Fang†
    arXiv, 2026
    paper / project page / code / X

    MATE combines diffusion policies that run at different rates without retraining them. It fuses vision and force for contact-rich tasks and combines camera views for occluded pick-and-place.

    Force Policy: Learning Hybrid Force-Position Control Policy under Interaction Frame for Contact-Rich Manipulation
    Hongjie Fang*, Shirun Tang*, Mingyu Mei*, Haoxiang Qin, Zihao He, Jingjing Chen, Ying Feng, Chenxi Wang, Wanxi Liu, Zaixing He, Cewu Lu, Shiquan Wang†
    RSS, 2026  
    paper / project page / code

    Force Policy learns an interaction frame from demonstrations to separate force and position control. It combines vision with fast local control to improve contact stability and force regulation.

    Scaling Cross-Embodiment World Models for Dexterous Manipulation
    Zihao He*, Bo Ai*, Tongzhou Mu, Yulin Liu, Weikang Wan, Jiawei Fu, Yilun Du, Henrik I. Christensen†, Hao Su†
    IROS, 2026
    paper / project page

    A shared world model represents hands and objects as 3D particles and transfers zero-shot across robot hands for plasticine reshaping.

    Learning Dexterous Manipulation with Quantized Hand State
    Ying Feng*, Hongjie Fang*, Yinong He*, Jingjing Chen, Chenxi Wang, Zihao He, Ruonan Liu, Cewu Lu†
    ICRA, 2026  
    paper / project page / code

    DQ-RISE represents hand poses with a compact set of discrete states. This simplifies motion prediction and lets a diffusion policy learn to coordinate arm and hand movements.

    AirExo-2: Scaling up Generalizable Robotic Imitation Learning with Low-Cost Exoskeletons
    Hongjie Fang*, Chenxi Wang*, Yiming Wang*, Jingjing Chen*, Shangning Xia, Jun Lv, Zihao He, Xiyan Yi, Yunhan Guo, Xinyu Zhan, Lixin Yang, Weiming Wang, Cewu Lu†, Hao-Shu Fang†
    CoRL, 2025 (oral)  
    paper / project page / data collection code / policy code

    AirExo-2 uses a low-cost exoskeleton to collect real-world demonstrations. In experiments, RISE-2 learns from these demonstrations and matches or exceeds policies trained on teleoperated robot data.

    FoAR: Force-Aware Reactive Policy for Contact-Rich Robotic Manipulation
    Zihao He*, Hongjie Fang*, Jingjing Chen, Hao-Shu Fang†, Cewu Lu†
    RA-L, 2025  
    IROS, 2025  
    paper / project page / code / X

    FoAR combines vision with force and torque sensing for contact-rich manipulation. By predicting contact, it adjusts how much it relies on force and torque as the task progresses.
